# CorelDRAW 2019（Windows）操作核對

查核日期：2026-09-19。以下依 **2019 官方說明（產品編號 540111130）**、官方快捷鍵卡，以及本機 2019 繁中說明核對。不要用新版頁面推斷 2019 選單。

## 可直接用於學生教材的操作

| 操作 | 2019 正確說法 | 來源 |
|---|---|---|
| 新建 | `Ctrl+N`；「檔案 → 新增」。新文件對話框的「繪圖單位」選毫米（mm）；「寬度／高度」是頁面大小。 | [2019 快捷鍵卡](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Quick-Reference-Card/CorelDRAW-Graphics-Suite-2019-shortcuts.pdf)、[開始及開啟繪圖](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Starting-and-opening-drawings.html) |
| 選取工具 | 左側工具箱的黑色箭頭。用於選取、調整大小、傾斜及旋轉。繁中官方名稱為「選取」工具。 | [Toolbox](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Exploring-the-toolbox.html) |
| 矩形 | `F6`；用矩形工具拖曳對角建立。先畫大約大小，再輸入精確尺寸。 | [2019 快捷鍵卡](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Quick-Reference-Card/CorelDRAW-Graphics-Suite-2019-shortcuts.pdf)、本機 `CorelDRAW-Drawing-rectangles-and-squares.html` |
| 精確寬高 | 選取物件後，在上方屬性列的「物件大小」欄輸入尺寸。要分別設定寬和高，須解除維持比例；鎖頭實際狀態與位置請由主工作實際截圖核對。**不要把左側 X、Y「位置」誤當宽高。** | [Size and scale objects](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Size-and-scale-objects.html) |
| 解除比例的選單備援 | 「視窗 → 泊塢視窗 → 變形」，選「大小」，停用「按比例」，X 是寬、Y 是高，再套用。此處 X/Y 為「變形／大小」區的欄位，與上方位置 X/Y 不同。 | 本機 `CorelDRAW-Skewing-and-stretching-objects.html` |
| 再製 | `Ctrl+D`；繁中選單是「編輯 → 再製」。複本可能有偏移，**不可寫成預設在原地**。再製偏移為 0 才重疊原物件。 | [Copy, duplicate, and delete objects](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Copy-duplicate-and-delete-objects.html) |
| 偏移設定 | 「配置 → 文件選項 → 一般」的水平、垂直再製偏移。官方英文網頁：Layout → Document Options → General → Horizontal/Vertical。正值往右／上、負值往左／下。適合簡單教材：再製後直接移開，再改尺寸；毋須教複雜偏移。 | 同上 |
| 多選及對齊 | 用選取工具逐一選物件，後選者作為對齊參考。菜單「物件 → 對齊與分佈」。建議用「先選要移動的物件，再按住 Shift 點固定參考物件」。 | [Align and distribute objects](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Align-and-distribute-objects.html) |
| C 對齊 | **C：左右置中，讓中心 X 相同；物件沿同一條垂直中線。** 2019 英文快捷鍵卡標為 Align Centers Horizontally。繁中說明為「水平置中對齊」。 | [2019 快捷鍵卡](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Quick-Reference-Card/CorelDRAW-Graphics-Suite-2019-shortcuts.pdf)、上述 Align 頁 |
| E 對齊 | **E：上下置中，讓中心 Y 相同；物件沿同一條水平中線。** 2019 英文快捷鍵卡標為 Align Centers Vertically。繁中說明為「垂直置中對齊」。不要把「沿水平軸」誤叫成「水平置中」。 | 同上 |
| 頁面正中 | `P` 為全部所選物件對齊頁面正中，不能用作對齊另一物件的代替。 | 同上 |
| 填色 | 先選物件，再用滑鼠**左鍵**點色盤色塊，設定填色。 | [Choose colors](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Choose-colors.html) |
| 外框顏色 | 先選物件，再用滑鼠**右鍵**點色盤色塊，設定外框顏色。這是預設行為；自訂色盤設定可以把右鍵改成選單。 | 上述 Choose colors、[色盤設定](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Set-color-palette-properties.html) |
| X 色塊 | 色盤頂端「無色」的 X 是**用滑鼠點擊的色塊，不是按鍵盤 X**。右鍵點無色色塊＝取消外框；左鍵點無色色塊＝無填色。官方另給無填色備援：互動式填色工具 → 屬性列「無填色」。 | [移除外框](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Copy-convert-remove-replace-outlines.html)、[Work with fills](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Working-with-fills.html)。鍵盤 X 在快捷鍵卡其實是橡皮擦。 |
| 匯入 | `Ctrl+I`；「檔案 → 匯入」。SVG 支援匯入。 | [2019 快捷鍵卡](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Quick-Reference-Card/CorelDRAW-Graphics-Suite-2019-shortcuts.pdf)、[SVG](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Scalable-Vector-Graphics-SVG.html) |
| SVG 比例 | 「匯入 SVG 檔案」對話框：**自動**採來源檔案比例；**公制（1 單位 = 1 mm）**按每單位一毫米解讀；另有「縮放」清單。對已明訂 width/height 毫米和正確 viewBox 的教材 SVG，建議先採自動、1:1，再核對物件寬高。不能一律保證所有 SVG 只選公制就保持原尺寸。 | 上述 SVG 頁；後一句為依文件格式的實務建議，仍需匯入樣檔驗證。 |
| 匯入定位 | 匯入游標出現後，在頁面**單擊一次**可保留檔案尺寸；**拖曳會改尺寸**。按 Enter 會放到頁面中央。 | [Import files](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Importing-files.html) |
| 文字 | `F8` 啟動文字工具。單字或一行短字適合藝術文字。 | [2019 快捷鍵卡](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Quick-Reference-Card/CorelDRAW-Graphics-Suite-2019-shortcuts.pdf)、本機 `CorelDRAW-Adding-and-manipulating-text.html` |
| 轉曲線 | 先用選取工具選文字，`Ctrl+Q`；「物件 → 轉換成曲線」。轉換後保留外觀，但不能再用文字工具改字；建議另存一份仍可改字的版本。 | [2019 快捷鍵卡](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Quick-Reference-Card/CorelDRAW-Graphics-Suite-2019-shortcuts.pdf)、[Curve objects](https://product.corel.com/help/CorelDRAW/540111130/Main/EN/Documentation/CorelDRAW-Using-curve-objects.html)、本機 `CorelDRAW-Finding-editing-and-converting-text.html` |

## 教材易錯處

1. 官方 2018 快捷鍵卡把 C/E 文字標法寫成另一順序；本工作只依 **2019 卡**，並以 X、Y 及垂直／水平中線解釋結果。
2. 「屬性列」隨目前工具與物件改变；要看物件尺寸，先選取物件。沒有選物件時，寬高可能是頁面尺寸。
3. 再製複本可能偏移，不能視為一定重疊；`Ctrl+D` 的參數也可能承接前一次變形，教材不應靠默认偏移完成精密定位。
4. 木工／雷射加工的實際切割線顏色、外框粗細、刀縫補償，必須依老師／機器設定；不可把畫面色塊等同固定加工規則。
5. **屬性列鎖頭的具體繁中提示名稱尚未由本研究確定。** 官方 2019 尺寸頁未文字說明該鎖頭。可用實際軟體截圖確認；已提供官方「變形／大小 → 停用按比例」備援。
