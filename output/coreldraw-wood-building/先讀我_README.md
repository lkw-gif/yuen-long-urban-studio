# CorelDRAW 2019 木板建築教材

適用：中二學生、Windows CorelDRAW 2019、名義厚度 2 mm 木板。

## 先開哪個檔案？
1. 開「01_學生指南.pdf」，先跟做 W1 單層小屋。
2. 到 templates 內選 W1 至 W6。SVG 是可編輯向量範本。
3. 在 CorelDRAW 按 Ctrl+I，選 SVG；比例先用自動／1:1。匯入游標出現後單擊，勿拖拉縮放。
4. 每張 SVG 各用一個新文件。核對毫米尺寸後，另存 CDR。
5. 切割前把設計及「02_教師設定表.pdf」交老師。

## 教材內容
- 31 頁中文學生指南：跟做小屋、滑鼠按鍵圖示、六款建築的排版及板件尺寸、組裝。
- 31 頁英文學生指南：與中文版相同內容及頁序，檔案為「01_Student_Guide_English.pdf」。
- 1 頁教師設定表：材料、試切、加工設定及核對欄。
- 6 款建築、9 張 SVG、84 件板材。
- W1 單層小屋：1 張／6 件。
- W2 兩層退台建築：1 張／12 件。
- W3 三層商場：2 張／18 件。
- W4 L 形學校：1 張／12 件。
- W5 U 形學校：2 張／18 件。
- W6 雙塔商業樓：2 張／18 件。

## 尺寸及工序
- 所有盒子的外尺寸包含頂板及底板；牆板尺寸已扣板厚，毋須再扣。
- 頂／底板蓋住牆；側牆夾在前／後牆之間。
- 紅外框是切割，藍線是門窗表面線刻。顏色只是課堂分類，老師必須在實際加工軟件指定工序。
- SVG 用 0.1 mm 顯示線寬；未做切縫補償。300 × 200 mm 是教學排版尺寸，不代表機器工作範圍。
- PDF 是閱讀參考，圖像按頁面縮放，不能把 PDF 頁面當作 1:1 切割檔。
- 門窗先只雕刻，不穿孔。各盒先組裝完成，再疊起或並排黏合。

## 儲存名稱
班別_組別_模型代號_數量.cdr
例如：2B_GROUP 2_W1_1.cdr
兩張排版分別加 _S01、_S02，例如：2B_GROUP 2_W3_1_S01.cdr。
「數量 1」是一套完整建築，並非一件木板。

## 教師核對及來源
已檢查向量檔結構、板厚尺寸公式、84件零件數量、頁邊及零件間距；未完成 CorelDRAW 實際匯入及實機切割測試。請先匯入 W1，量頂板 80 × 60 mm，再試切試拼，按實測板厚與切縫調整。
